# 学習計画

期間などは決めておらず、手順や内容、教材などを含めたものになっている。**メイン教材はすべて無料**で、手持ちの教科書は「並行して読む補助線」として使う。

## 基本方針

- **無料教材がペースメーカー**: 無料教材(講義・オンライン書籍)で決めます。
- **教科書は深掘り用**: 同じトピックの章を並行して読み、証明・詳細・演習問題で理解を補強。教材で「なんとなく分かった」ところを、教科書で「きちんと分かった」に変えるイメージ。
- **理論と実装を1セットにする**: 読む → Rustで実装 → テスト・計測、を回す。
- **標準ライブラリに頼らず自作する**: Vec、HashMap、スレッドプール、パーサーなどを書くと、所有権・ライフタイムの理解も深まる。

## フェーズ1: Rust基礎

**無料教材**

- The Rust Programming Language(公式Book。日本語版あり)
- Rustlings(練習問題)
- Rust by Example
- Too Many Linked Lists(所有権の理解に最適)

**教科書で並行して読むなら**: Rust関連の書籍を持っていれば、公式Bookと同じ章を読み比べると理解が早まる。

**目標**: 所有権・借用・トレイト・エラー処理・イテレータを一通り書ける

**課題**: CLIツール(grepもどき)を1つ作る(公式Bookの最終章のプロジェクトも参考になる)

## フェーズ2: データ構造とアルゴリズム

**無料教材**

- MIT 6.006(OCWの講義動画・ノート)
- _Algorithms_(Jeff Erickson、無料PDF)
- _Open Data Structures_(無料オンライン書籍。実装寄りでRustと相性が良い)
- AtCoder(Beginners Selection、競プロ典型90問)

**教科書で並行して読むなら**: 『アルゴリズムイントロダクション』(CLRS)、『プログラミングコンテストチャレンジブック』、アルゴリズム系の教科書全般。各週のトピックに対応する章を、計算量の証明と演習問題を中心に読む。

**内容**: 配列・連結リスト・ハッシュ表・木(平衡木、B木)・ヒープ・グラフ・DP・計算量解析

**課題**: Vec、HashMap、BTreeMapを自作し、`criterion`でベンチマークして標準ライブラリと比較する

**並行して**: AtCoderを週2〜3問、Rustで解く

## フェーズ3: コンピュータアーキテクチャ・OS

**無料教材**

- OSTEP(_Operating Systems: Three Easy Pieces_、無料オンライン書籍)
- nand2tetris(Part 1・Part 2とも無料)
- CMU 15-213(CS:APPの講義動画・スライド・ラボが公開)
- MIT 6.S081(xv6、講義・ラボとも無料)
- _Writing an OS in Rust_(blog_os、無料ブログ連載)
- CHIP-8エミュレータの解説記事(Rust向けのものも多数あります)

**教科書で並行して読むなら**: CS:APP(『詳解コンピュータシステム』)、『コンピュータの構成と設計』、OS系の教科書。15-213の講義と同じ章を並行して読むのが特におすすめ。

**内容**: 2進表現・アセンブリ・キャッシュ・メモリ階層・プロセス・仮想メモリ・スケジューリング・ファイルシステム

**課題**:

- 簡単なVM(CHIP-8エミュレータなど)
- `malloc`風アロケータ、シェル自作(`fork/exec`は`nix`クレート)
- 余裕があれば blog_os を最後まで

## フェーズ4: 言語処理系

**無料教材**

- _Crafting Interpreters_(Robert Nystrom、全文無料オンライン。Rustに移植しながら進める)
- _Let's Build a Compiler_(Jack Crenshaw、無料。小さく作る感覚をつかめます)

**教科書で並行して読むなら**: 『コンパイラ(ドラゴンブック)』、プログラミング言語・型システム関連の教科書。字句解析・構文解析・最適化の理論面を補強できる。

**内容**: 字句解析・構文解析・AST・インタプリタ・バイトコードVM・GC

**課題**: 自作言語のバイトコードVMまで作る

## フェーズ5: ネットワークと並行処理(8週)

**無料教材**

- _Rust Atomics and Locks_(Mara Bos、著者サイトで全文無料公開)
- Tokioチュートリアル(公式、無料)
- Beej's Guide to Network Programming(無料)
- Stanford CS144(講義資料・ラボが公開)
- Kurose & Ross 『Computer Networking』関連の講義動画(著者が公開)
- 公式Bookの「マルチスレッドWebサーバー」章

**教科書で並行して読むなら**: 『Computer Networking: A Top-Down Approach』、『詳解TCP/IP』などのネットワーク系教科書、並行処理・OS系教科書の同期の章。

**内容**: TCP/IP・HTTP・ソケット・非同期I/O・メモリモデル・ロック・アトミック操作

**課題**: HTTPサーバーを`std::net`のみで自作 → スレッドプール → `tokio`版に書き直して比較

## フェーズ6: データベースと分散システム(8週)

**無料教材**

- CMU 15-445(講義動画・スライド・課題が公開)
- MIT 6.824(現6.5840、講義・ラボとも無料)
- PingCAP Talent Plan(Rustで書くKVストアのコース。無料)
- mini-lsm(LSM木をRustで作る無料コース)
- Raft論文と公式サイト(raft.github.io)
- Martin Kleppmannの分散システム講義(ケンブリッジ大、動画公開)

**教科書で並行して読むなら**: 『Designing Data-Intensive Applications』、データベース系教科書。講義で出てきた概念(レプリケーション、トランザクション分離レベルなど)の背景を読むのに最適。

**内容**: ストレージエンジン(LSM木/B木)・トランザクション・WAL・レプリケーション・Raft

**課題**: Talent PlanまたはKVストア自作 → WAL追加 → mini-lsmでLSM木 → Raftの簡易実装

## フェーズ7: 統合プロジェクト(4週)

これまでの成果を1つにまとめる。たとえば「自作言語で動く、永続化付きの分散KVストア」のように、興味のある領域で選ぶ。

## 続けるためのコツ

- 完璧に理解してから進まず、**80%分かったら次へ**。後のフェーズで戻ると定着します。
- 教科書は「全部読む」のではなく、無料教材の週ごとのトピックに対応する章だけを読みます。
- フェーズごとに「何が分かったか、何が分からないか」を1ページにまとめる。
- 詰まったら公式フォーラム(users.rust-lang.org)やRust日本語コミュニティで質問する。
